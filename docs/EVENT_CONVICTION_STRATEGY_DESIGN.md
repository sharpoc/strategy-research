# 事件信念统一框架设计

最后更新：`2026-04-02`

## 目标

把当前“核心高管连增臻选”从单一事件策略，升级成一个可扩展的母策略：

- 不只看高管增持
- 把“公司/核心资金在主动表达态度”的事件统一纳入
- 统一输出：
  - 候选池
  - 事件强度
  - 身份强度
  - 市场确认
  - 最终轻确认排序

一句话：

`谁在表达 + 表达强不强 + 市场认不认`

## 为什么现在要做

当前 `core_management_accumulation` 已经证明：

- 单一事件源本身是有价值的
- `stage1` 和 `final` 的分层思路是对的
- 真正的问题不再是“能不能识别事件”
- 而是：
  - 单一事件池太窄
  - `final` 对某一类结构过拟合

所以更长期的正确方向不是反复微调“高管增持”四个字，而是把它变成一个更通用的事件信念框架。

## 第一版纳入的事件类型

第一阶段建议只纳入最接近“真金白银表态”的事件：

1. 核心高管增持
- 当前已有
- 保留为最高优先级事件之一

2. 重要股东/实控人增持
- 比普通股东更有参考价值
- 需要单独做身份权重

3. 公司回购
- 本质是公司层面的资本动作
- 需要区分：
  - 董事会通过/计划发布
  - 实际回购发生
  - 回购金额兑现进度

4. 员工持股 / 股权激励
- 偏“经营层长期绑定”
- 需要避免把纯公告噪音直接当买点

5. 业绩拐点类事件
- 例如：
  - 业绩预增
  - 扭亏
  - 盈利大幅改善
- 不能直接等同于资金承诺，但可作为辅助增强

## 统一分层

### 1. Event Layer

回答：

`发生了什么`

每个事件标准化后至少要有：

- `event_type`
- `event_date`
- `ts_code`
- `event_direction`
- `event_amount`
- `event_strength_raw`

### 2. Identity Layer

回答：

`是谁做的`

建议权重优先级：

- 公司本体 / 实际回购
- 实控人 / 控股股东
- 董监高 / 核心管理层
- 产业资本 / 战投
- 普通重要股东

输出：

- `identity_role`
- `identity_weight`
- `identity_group`

### 3. Conviction Layer

回答：

`这个动作有多真`

核心维度：

- 金额强度
- 连续性
- 密集度
- 占流通盘比例
- 是否真实发生而非仅公告

输出：

- `amount_score`
- `continuity_score`
- `density_score`
- `execution_score`
- `conviction_score`

### 4. Market Confirmation Layer

回答：

`市场有没有认这个动作`

建议沿用当前 `core_management` 的成熟部分：

- 成本区位置
- 均线状态
- 是否跌破结构
- 量价修复
- 主力净流 / 融资净买入 / 换手健康度

输出：

- `cost_zone_score`
- `structure_score`
- `flow_health_score`
- `confirmation_score`

### 5. Final Layer

回答：

`今天该不该出最终信号`

只做轻确认：

- 去重
- 最近相同事件波冷却
- 结构未坏
- 至少有一个明确的确认信号

不再承担“定义事件”的责任。

## 与当前策略的关系

当前 `core_management_accumulation` 不废弃，而是转成这个框架下的一个子策略：

- 子策略 id：
  - `core_management_accumulation`
- 对应事件源：
  - `management_buy`
- 主要优势：
  - 身份强
  - 资金表达直接
  - 与成本区关系明确

后续可以继续追加：

- `shareholder_buy`
- `company_buyback`
- `equity_incentive`
- `earnings_turnaround`

## 第一版落地建议

先不要一次做成大而全。建议按这个顺序推进：

1. 抽出统一事件记录结构
2. 先接入：
   - `management_buy`
   - `company_buyback`
3. 复用当前 `stage1 / final` 思路
4. 先做研究态，不接网页、不接线上

## 暂时不要做的事

- 不要一次接太多事件源
- 不要把所有公告都当利好
- 不要把“事件池扩大”误当成“策略一定变强”
- 不要跳过统一字段定义直接拼 patch

## 当前结论

当前最合理的中期方向是：

`把核心高管连增臻选升级成“事件信念统一框架”中的第一条子策略，再逐步把回购等强事件接进来。`
